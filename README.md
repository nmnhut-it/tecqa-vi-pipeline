# tecqa-vi-pipeline

Auto-synced mirror of `tecqa/` from the (private) TECQA-VI course project --
the TECQA pipeline code only, published here so
`notebook/tecqa_vi_colab.ipynb` can `git clone` it without needing access to
the private main repo.

This is a **code mirror, not a project**: no dataset, no paper, no docs, no
commit history from the source repo. It is overwritten and force-pushed by
`scripts/publish_pipeline_repo.py` every time the pipeline changes -- don't
open PRs here, they will be lost on the next sync.

Full project (private): https://github.com/nmnhut-it/nlp-final-project
